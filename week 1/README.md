# Week 1: Linux Fundamentals & C Language Introduction

This module introduces core Linux command-line operations, package management, and basic C compilation pipelines.

## Contents
- **[Lab 1: Linux Fundamentals](./lab1.docx)**:
  - File management commands: `mkdir`, `cd`, `nano`, `cat`, `cp`, `mv`, `rm`, `rmdir`, `ls -l`.
  - Package installation: `apt update`, `apt install build-essential`, `gcc --version`.
  - Simple compilation, warning flags (`-Wall`), and iterative development.
- **[Lab 2: C Programming Basics & Compilation Stages](./lab2/)**:
  - Detailed 4-stage GCC compilation pipeline (`.i`, `.s`, `.o`, and executable).
  - Exit code inspection via `echo $?`.
  - Formatted input/output (`scanf`, `printf`).
- **Classroom Exercises**:
  - `day3.c`: Introductory C execution.
  - `input.c`: User integer input processing.
  - `function.c`: Function prototypes and structured code organization.
