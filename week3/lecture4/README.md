# Lecture 4: Process Memory Segments & Data Representation

Practical code examples and conceptual review exploring how the Linux operating system structures process address spaces.

## Contents
- `task1.c`: Evaluates data type byte sizes on the system using `sizeof()`.
- `task2.c`: Maps virtual addresses across Data, BSS, Heap, and Stack memory segments using `%p`.
- `task1.asm`: Disassembled/assembly representation of memory operations.
- `knowledgecheck.txt`: Direct notes and Q&A covering memory segment definitions, CPU stack pointers, memory leaks, and OS page tracking.
